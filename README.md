# StayKota

Frontend-only Hostel and PG discovery experience for students in Kota, Rajasthan.

## Current slice

- Responsive Home/Search page inspired by the supplied reference
- Mock hostel listings with multiple room types and separate pricing
- Locality, budget, gender, sharing, food, and AC search controls
- Search navigation that preserves selected filters in the URL
- Responsive results page
- Student-focused benefits, steps, footer, loading-ready card structure, and demo labels
- Placeholder routes for upcoming hostel details, login, owner, and 404 experiences

All listing content and actions are mock frontend data. No backend, authentication, payments, or real availability are connected yet.
